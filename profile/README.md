# Gaffa - Browser Automation REST API

## Overview

Gaffa is a simple REST API for browser automation that eliminates the need for frameworks, proxies, scaling, headless browsers and configuration. It allows you to control real browsers at scale with a single API call, so you can scrape, extract data, take screenshots and automate websites without managing any infrastructure.

## Getting Started

You can start using Gaffa now by signing up at https://gaffa.dev

## Gaffa's GitHub Repositories

### 1. **Docs** Repository
- Documentation for the Gaffa web automation API - feel free to contribute if you think we've missed something! https://gaffa.dev/docs

### 2. **GaffaPythonExamples** Repository
- Examples from the Gaffa blog that are built with Python: https://github.com/GaffaAI/GaffaPythonExamples

### 3. **gaffa-for-ai** Repository
- AI Skills and tools for integrating Gaffa browser automation with AI agents: https://github.com/GaffaAI/gaffa-for-ai

### 4. **gaffa-cli** Repository
- The Gaffa command line tool for setting up your AI coding tools with the Gaffa skills (`npx @gaffa-dev/cli`): https://github.com/GaffaAI/gaffa-cli

### 5. **GaffaNodeSamples** Repository
- Examples of what you can build with Gaffa using Node.js: https://github.com/GaffaAI/GaffaNodeSamples
